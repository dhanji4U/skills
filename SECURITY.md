# Security Policy

## Supported Versions

Only the latest commit on the `main` branch is actively supported with security updates.

| Version | Supported |
|:--------|:----------|
| main    | Yes       |
| < 1.0.0 | No        |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

To report a vulnerability:
1. Use GitHub Private Vulnerability Reporting on this repository.
2. If private reporting is unavailable, email `dhanjibhagat@gmail.com` with full technical details.

### What to Include
- Description of the issue and potential impact.
- Step-by-step reproduction instructions or proof of concept.
- Affected skills or scripts.

### Response Timeline
- An acknowledgment will be sent within 48 hours of receipt.
- A status update or fix timeline will be provided within 5 business days.
- A public advisory will be issued once a patch has landed.
